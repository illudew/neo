01 / 阶段地图

三个阶段，一条主线。

阶段 A · 小初高数学数、运算、方程、函数、图形与数据——一切物理量纲与图像的起点。阶段 B · 初等数学桥梁证明方法、古典几何、组合与离散推理——从"会算"走向"会证"。阶段 C · 数学系核心十三门课程的系统路线：分析线、代数线与概率线并行推进。

三条并行路线：分析线 微积分 → 常微分方程 → 矢量分析 → 偏微分方程 → 傅里叶分析 → 复变函数 → 实变函数 → 泛函分析；代数线 线性代数 → 群论 → 拓扑（并衔接数论）；概率线 组合计数 → 概率论与数理统计 → 统计物理。不要按编号从头学到尾——按两年规划与你的物理问题选课。

02 / 怎么用这份课程表

每门课只回答三个问题。

为什么需要：给出这门课在物理学中的真实用途，而不是"数学很美"。学到什么程度：列出核心内容与一个明确的停止信号——多数物理方向不需要数学系的完整深度。怎么检查：每课附一道自测与一个产物任务；能完成产物，就可以继续下一门。

十三门课全部"学过"但都不会用，不如精通微积分、线性代数与常微分方程后带着真实问题回补。本页的依赖图比完成度更重要。

阶段 A / 无需先修

小初高数学：物理语言的字母表。

为什么需要：每一个物理公式都在用这个阶段的零件。量纲是幂运算，图像是函数，受力分解是三角，误差条是数据与均值。这一阶段的目标不是"会做题"，而是把每个符号与一个物理量绑定。

数与运算：分数、幂、根 → 比例与量纲 LT⁻¹
代数式与方程：因式分解、移项 → 公式反解
函数与图像：线性、二次、指数、对数、三角 → 物理曲线
几何与三角：平面几何、正弦余弦定理 → 光路与力
数据与随机：平均、离散、简单概率 → 误差条与计数

核心线索：指数与对数决定你能否理解放射衰变与能标；三角函数决定你能否读懂波动；"函数是输入输出的对应关系"这一观念，是后面一切（分布、算符、态）的地基。

学到什么程度：能徒手画出 v–t、F–x、势能曲线并读出斜率与面积的物理含义；能把 sin、log 的自变量说清是否无量纲。达到后即可进入量纲单元。

自测：为什么 ln(2 m) 是错误写法？

对数、指数与三角函数的自变量必须无量纲。正确写法是 ln(ℓ/ℓ₀)，其中 ℓ₀ 是参考长度；比值的对数才不随单位制改变。

产物：列一张"符号—物理量—单位"对照表，覆盖分数幂、三角、指数对数各一个真实公式（如衰变律、单摆、欧姆定律）。

阶段 B / 先修：阶段 A

初等数学：从会算到会证。

为什么需要：数学系课程的第一道墙不是难度，而是文体——定义、定理、证明。不先学会"反证"与"归纳"，会在实变函数与抽象代数里同时迷路。这一阶段是桥梁，不是内容本身。

证明方法：直接、逆否、反证、数学归纳法
古典几何：欧几里得公理体系、尺度圆规作图
组合与离散：计数、抽屉原理、简单图论
初等数论：整除、素数、模运算

核心线索：归纳法证明 1+2+…+n = n(n+1)/2，与归纳法定义数列递推，是同一种思维；欧几里得"五条公理推出全部"让你第一次见到公理化——它将在拓扑与群论中反复出现。非欧几何的伏笔（第五公设独立）是广义相对论的数学前史。

学到什么程度：能独立写出一个反证（如 √2 无理）与一个归纳证明；能解释鸽巢原理为什么保证"至少一个"。达标即可进入阶段 C。

自测：模 7 意义下 3⁶ ≡ 1，用它能心算什么？

3²⁰²⁶ mod 7：2026 = 6×337 + 4，故等价于 3⁴ = 81 ≡ 4。模运算把大指数压缩到有限集合——这正是群论中"阶"的雏形。

产物：用反证法证明素数有无穷多个，再用归纳法证明一个求和公式；注明每一步用了哪种推理规则。

C1 · 微积分（数学分析）/ 先修：阶段 A、B

微积分：把"变化"变成可计算的对象。

为什么需要：物理定律几乎总写成变化率或累积量。牛顿第二定律是导数，功是积分，Taylor 近似是"局部线性化"的定量版本。不会微积分，物理公式只是咒语。

f(x+Δx) ≈ f(x) + f′(x)Δx + ½f″(x)Δx² + …
W = ∫ F(x) dx，dU/dt = ∂U/∂t + ∇U·v
Σ 1/n 发散，Σ 1/n² 收敛：级数需要判别

核心内容：单变量微分与积分（中值定理、Taylor 公式、Newton–Leibniz）；多变量微积分（偏导、链式法则、重积分、隐函数与极值）；无穷级数与一致收敛的初步观念。数学分析教材（如 Ch. Walter 或国内"数分"）比工科"高数"多出的部分——确界原理、收敛判别——正是你后面需要的严格性训练。

物理学家停在哪：会做 Taylor 展开并估计余项、会在曲线坐标下换元积分、能判断级数是否收敛，即可继续。测度式的积分理论留给实变函数。

自测：为什么 sin θ ≈ θ 只在 θ 以弧度为单位时成立？

Taylor 系数 −1/6 来自对 sin 求导两次，而 (d/dθ)sin θ = cos θ 只对弧度成立；角度制会引入 π/180 的因子，一阶近似系数不再是 1。

产物：对单摆恢复力做二阶 Taylor 近似，写明余项量级与适用角度范围。配套阅读 导数单元 与 积分单元。

C2 · 线性代数 / 先修：平面坐标与矩阵乘法

线性代数：多自由度世界的语法。

为什么需要：耦合振子的简正模式、转动惯量主轴、量子力学的态叠加与测量、数据拟合的最小二乘——全是同一个问题：线性映射在什么基下最简单。线性代数是物理中使用频率最高的一门课。

Av = λv：不变方向与缩放因子
A = QΛQᵀ（实对称谱分解）
⟨u,v⟩ = uᵀMv：带度量的内积

核心内容：向量空间、子空间与基；线性映射与矩阵（二者是对象与表示的关系）；行列式的几何意义（体积缩放）；特征值与对角化；内积空间、正交性与投影；实对称/厄米矩阵的谱定理；二次型与 SVD 初步。

物理学家停在哪：能对角化 2×2 与 3×3 实对称矩阵并解释其物理（简正模式频率、主轴），能把量子力学的"态=向量、 observable=厄米矩阵"讲清楚，就够支撑后续课程。抽象模理论不必深入。

自测：矩阵相似 A′ = P⁻¹AP 时，什么不变？

特征多项式、特征值、迹与行列式不变——它们是线性映射本身的性质；特征向量的分量则随基改变。这正是"对象不变、表示改变"的第一个例子。

产物：写出双摆小角近似的动能与势能矩阵，广义特征值问题 M⁻¹K 求出两个简正频率。配套 向量与矩阵单元。

C3 · 概率论与数理统计 / 先修：微积分、组合计数

概率与统计：从有限观测到可信结论。

为什么需要：测量有噪声，统计物理以概率为语言，量子力学Born 规则直接是概率公理。物理学家需要的不是"背分布表"，而是能判断一个结论在数据下是否成立。

P(A∪B) = P(A)+P(B)−P(A∩B)
大数定律：x̄ → μ；中心极限：√n(x̄−μ)/σ ⇒ N(0,1)
似然 L(θ) = Π p(xᵢ|θ)，MLE 取 argmax

核心内容：概率空间与条件概率、独立性；随机变量、分布与密度（换元与卷积）；数字特征；大数定律与中心极限定理（条件版本）；参数估计（矩法、MLE、Cramér–Rao 直觉）；假设检验与置信区间；贝叶斯公式与先验的作用。

物理学家停在哪：能推导理想气体速率分布的归一化、能从计数数据写出 Poisson 似然并拟合、能解释 p 值不是什么，即可。测度论概率的严格化在实变函数之后选修。

自测：100 次独立重复中事件发生 0 次，能否断言其概率为 0？

不能。若 p = 0.01，(1−p)¹⁰⁰ ≈ 0.37，观测到 0 次完全正常。应报告置信上界（约 3/100 量级），而不是点估计 0。

产物：给一组带噪测量做 MLE 拟合并报告参数不确定度，注明独立性假设是否成立。配套 统计单元 与 误差传播。

C4 · 矢量分析 / 先修：多元微积分

矢量分析：场的微积分。

为什么需要：电磁、流体、引力都是空间中的场。Maxwell 方程组的微分形式、流体力学的连续性方程，全部用 ∇、div、curl 写成三个短公式——不用矢量分析就要写一百二十个分量方程。

∇·E = ρ/ε₀，∇×B = μ₀J + μ₀ε₀∂E/∂t
∮_C F·dr = ∬_S (∇×F)·dS（Stokes）
∯_S F·dS = ∭_V ∇·F dV（Gauss）

核心内容：标量场与矢量场；梯度、散度、旋度的定义与物理直觉（最速上升、通量源、环流密度）；线面积分与三类基本定理（Green、Stokes、Gauss）；正交曲线坐标（柱、球）下的算子形式；Helmholtz 分解初步。

物理学家停在哪：能把积分形式的定律改写为微分形式、能在球坐标下算点电荷的散度并理解 δ 函数的出现，即可。曲线坐标的严格几何（微分形式）由张量单元衔接。

自测：∇×(∇f) = 0 对任何光滑 f 成立，它的物理推论是什么？

保守力场无旋，因而沿闭合路径做功为零、可定义势能。反过来说，感应电场 ∇×E ≠ 0 意味着"电压"在变化磁场区域不再是良定义的路径无关量。

产物：用 Gauss 定理求均匀带电球内外的电场，再直接积分验证一处。这是矢量分析最标准的物理演练。

C5 · 复变函数 / 先修：微积分、Euler 公式

复变函数：解析性带来的杠杆。

为什么需要：复可导的条件远强于实可导，因此"解析"几乎自动给出一切：留数定理把最难的实积分变成代数运算，解析延拓把色散关系与因果性联系起来，共形映射解二维场问题。量子力学的复数更是不可回避的语言。

∂u/∂x = ∂v/∂y，∂u/∂y = −∂v/∂x（Cauchy–Riemann）
∮_C f(z)dz = 2πi Σ Res(f, 极点)
f(z) = Σ aₙ(z−z₀)ⁿ ↔ 无穷次可导

核心内容：解析函数与 Cauchy–Riemann 方程；Cauchy 积分定理与积分公式；Laurent 级数与留数计算（含实积分）；共形映射与二维 Laplace 问题（绕流、平面静电）；解析延拓与多值函数（sqrt、log 的分支）；留数在物理积分（Kramers–Kronig、Feynman 传播子 iε）中的用法。

物理学家停在哪：能用留数计算 ∫₀^∞ dx/(1+x²) 类积分、能解释极点与共振寿命的关系（E → Γ/2），即可。单值化与黎曼曲面深理论按需选修。

自测：e^(1/z) 在 z = 0 是什么奇点？留数是多少？

本性奇点（Laurent 主部无穷项）。展开 e^(1/z) = Σ z⁻ⁿ/n!，z⁻¹ 系数为 1，故留数为 1。极点阶数有限才可用求导公式，此处必须回级数。

产物：用留数计算 ∫₋∞^∞ dx/(x²+1)²，并说明为什么上半圆的大弧贡献消失（Jordan 引理条件）。

C6 · 实变函数 / 先修：微积分、证明方法

实变函数：把积分与极限做扎实。

为什么需要：物理计算里"先积分再取极限"和"先取极限再积分"天天互换次序，而合法性正是实变函数的内容。Lebesgue 积分同时是概率论的公理化地基（Kolmogorov）与量子力学 L² 空间的前提。

lim ∫ fₙ = ∫ lim fₙ 需要控制函数：|fₙ| ≤ g，g 可积
‖f‖₂ = (∫|f|² dx)½：平方可积函数构成空间
测度：可数并的"长度"，零测集不影响积分

核心内容：集合与基数；测度的构造（外测度→可测集）；可测函数与几乎处处收敛；Lebesgue 积分与三大收敛定理（单调、控制、Fatou）；Lp 空间初步；微积分基本定理的重新表述。

物理学家停在哪：能判断一次"极限与积分交换"是否合法、知道 Riemann 不可积但 Lebesgue 可积的例子、理解 L² 是完备内积空间（通往泛函分析），即可。一般测度空间与遍历理论按方向选修。

自测：Dirichlet 函数（有理点取 1，无理点取 0）为何 Riemann 不可积而 Lebesgue 可积？

任何区间内有理与无理都稠密，Riemann 和的振幅不收敛；但无理集测度为 1，函数几乎处处为 0，Lebesgue 积分存在且等于 0。这解释了"零测集可忽略"为何是物理中常见的默认前提。

产物：写出一次你熟悉的物理推导（如波包归一化随时间不变），指出其中哪一步需要控制收敛定理保证。

C7 · 傅里叶分析 / 先修：微积分、内积、复数

傅里叶分析：物理的第二语言。

为什么需要：线性系统用频率描述，晶体衍射是散射波的傅里叶变换，量子力学的位置与动量表象是一对 Fourier 变换，PDE 的分离变量本质是找 Laplace 算子的特征函数。这是使用频率仅次于微积分的工具。

f̂(ξ) = ∫ f(x)e^(−2πixξ)dx，f(x) = ∫ f̂(ξ)e^(2πixξ)dξ
卷积定理：ℱ(f∗g) = f̂·ĝ
不确定性：Δx·Δξ ≥ 1/4π

核心内容：三角 Fourier 级数与正交性；均方收敛与逐点收敛的区别（Dirichlet 条件、Gibbs 现象）；Fourier 变换及其性质（微分变乘法、卷积、缩放）；分布与 δ 函数的严格化；离散变换与采样、混叠；多维 Fourier 与衍射；特征函数展开的一般观点。

物理学家停在哪：会查会用变换性质表、能解"高斯脉冲经过色散介质"类问题、理解采样定理的适用条件，即可。调和分析的收敛理论深水区（Carleson 定理等）不必追。

自测：为什么方波的 Fourier 级数在跳变点不收敛到函数值？

逐点收敛到左右极限的平均 ½(f⁺+f⁻)，且部分和在跳变附近有约 9% 的过冲（Gibbs），项数增加只压缩过冲宽度、不压低高度。均方收敛仍然成立——两种"收敛"不是一回事。

产物：用 Fourier 变换解自由粒子的波包扩散 σ(t) = σ₀√(1+(ħt/2mσ₀²)²)。配套 Fourier 与采样单元。

C8 · 泛函分析 / 先修：线性代数、实变、傅里叶

泛函分析：把函数当作点。

为什么需要：量子力学的公理体系（态是 Hilbert 空间射线、可观测量是自伴算符、谱决定测量结果）就是泛函分析；变分法、Green 函数、散射理论都建立在无穷维空间的结构上。没有它，Dirac 记号只是类比。

Hilbert 空间：完备 + 内积；L² 是标准例子
自伴算符谱定理：Â = Σ λₙ|n⟩⟨n|（离散谱情形）
有界算符对偶：⟨f,x⟩ ↔ f ∈ H*

核心内容：赋范空间与完备性（Banach）；Hilbert 空间、正交基与投影定理；有界线性算符、伴随与自伴；谱定理（紧算符与无界自伴算符的陈述层面）；分布（广义函数）与 Sobolev 空间初步；压缩映射与变分问题可解性。

物理学家停在哪：能区分点谱/连续谱、解释为什么动量算符"本征态"不是态而是分布、知道 Stone 定理（自伴 ⇒ 幺正演化）的陈述，即可。C* 代数与算子代数留给量子场论与统计力学深方向。

自测：为什么动量算符 −iħ d/dx 的"本征态" e^(ipx/ħ) 不在 Hilbert 空间里？

它在无穷区间上平方不可积，不属于 L²。严格处理是 rigged Hilbert 空间/谱测度语言：它是广义本征函数，对应连续谱。这正是"无穷维不同于有限维"的标志性例子。

产物：证明一维无限深势阱的位置算符谱是纯点谱并写出本征函数系，与自由粒子的连续谱对照。

C9 · 常微分方程 / 先修：微积分、线性代数

常微分方程：从规律推回轨迹。

为什么需要：力学、电路、种群、宇宙学尺度因子——"给定变化规律求时间演化"就是 ODE。物理学家需要的不是解更多技巧方程，而是定性理论：解是否存在唯一、长期行为是什么、参数怎样改变行为。

x″ + 2βx′ + ω₀²x = F cos ωt：受迫阻尼振子
相平面：ẋ = y，ẏ = −sin x（单摆的轨道图）
Picard–Lipschitz：f 关于 x 局部 Lipschitz ⇒ 解局部唯一

核心内容：一阶方程（分离、线性、恰当）与初值问题；解的存在唯一性与延拓（Lipschitz 条件的反例）；线性方程组与矩阵指数 e^(At)；二阶常系数与振子系统；定性理论：相平面、平衡点分类、极限环与分岔初步；幂级数解（Legendre、Bessel 的物理出身）。

物理学家停在哪：会矩阵指数解线性系统、能用相平面判断阻尼与极限环、知道"通解可能漏掉奇解（如 y′=y^(2/3) 的 y≡0）"，即可。动力系统严格理论按方向选修。

自测：为什么 x″ = −x³ 的周期依赖振幅，而 x″ = −x 的不依赖？

势能 ∝ x⁴ 不是二次型，方程无尺度不变性；量纲分析给出 T ∝ A^(−1)·(常数)，振幅改变即改变时间尺度。线性谐振子的 T = 2π/ω 与 A 无关正是叠加原理的另一面。

产物：画出阻尼单摆的相图（欠阻尼收敛、过阻尼滑移、驱动极限环三种情形各一条轨道）。配套 微分方程单元。

C10 · 偏微分方程 / 先修：ODE、矢量分析、傅里叶

偏微分方程：连续介质的动力学。

为什么需要：场是物理的基本对象。热传导、波动、静电势、Schrödinger、Navier–Stokes 全是 PDE；而"方程+区域+边界/初始条件才构成一个物理问题"这一观念，是数值模拟与解析求解共同的地基。

∂u/∂t = α∇²u（抛物）；∂²u/∂t² = c²∇²u（双曲）；∇²u = 0（椭圆）
分离变量：u = Σ bₙXₙ(x)Tₙ(t)，模式衰减或振荡
Green 函数：u = ∫ G(x,x′)s(x′)dx′，边界写进 G

核心内容：三类经典方程与特征（依赖区域、传播速度）；一阶方程特征线法；分离变量与 Sturm–Liouville 本征问题（正交性来源）；积分变换解全空间问题；Green 函数与 Poisson 公式；能量方法与唯一性、稳定性（well-posedness）初步；数值接口（见数值计算）。

物理学家停在哪：能在矩形、圆盘、球三种区域上分离变量（会查 Bessel/Legendre 表）、能用能量方法证明热方程解唯一、能判断一个问题适不适定，即可。线性算子谱理论视角由泛函分析补。

自测：为什么 Laplace 方程的解在区域内部没有局部极大值？

极值原理：调和函数的最值在边界取得。物理推论是稳态温度分布内部无热点、静电场内部无势阱——没有电荷就没有"势的局部极小"，这直接解释了 Earnshaw 定理。

产物：用分离变量解矩形薄膜的振动频率 ω_mn，并说明圆盘情形为何出现 Bessel 零点。配套 偏微分方程单元。

C11 · 群论（抽象代数入门）/ 先修：线性代数、集合与映射

群论：对称性的精确语言。

为什么需要：守恒律由对称性决定（Noether），基本粒子按 Poincaré 群的表示分类，晶体 230 个空间群决定衍射图谱，简并度与选择定则是表示论的直接推论。现代物理没有一处离开群论。

|G| = Σ|Clᵢ|，Lagrange：|H| 整除 |G|
表示：D(g₁g₂) = D(g₁)D(g₂)；特征标 χ = Tr D
SU(2) ⊃ SO(3) 二重覆盖：自旋 ½ 来自这里

核心内容：群、子群、陪集与 Lagrange 定理；正规子群与商群；群作用、轨道与稳定子（计数 Burnside 的入口）；表示与特征标表（有限群：Cₙ、Dₙ、Sₙ、立方群）；Lie 群与 Lie 代数初步（SO(3)、SU(2)、SU(3)）；Noether 定理的表述层面。

物理学家停在哪：会用特征标表分解表示、能解释角动量加法 = SU(2) 张量积分解、知道晶体点群如何限制张量形式（Neumann 原理），即可。表示环、代数群等纯数学方向不必深入。

自测：为什么电子绕核转 360° 波函数变号不构成矛盾？

物理态是射线（相差非零复数等价），SU(2) 中 2π 旋转给出 −I，与 4π 旋转（+I）在射影意义下都是恒等变换。SO(3) 的表示提升为 SU(2) 的表示，半整数自旋只存在于后者。

产物：写出 C₃ᵥ 的特征标表，把 p 轨道与 d 轨道按不可约表示分类，解释八面体场分裂。配套 群论单元。

C12 · 数论 / 先修：初等数论、群论入门

数论：离散结构的算术。

为什么需要：传统上这是物理学家最"用不上"的一门课——但边界正在移动：量子混沌研究能级统计与模形式，弦论与 AdS/CFT 用到自守形式，全同粒子与晶格的离散对称本质是算术问题；而数论是训练"有限对象上的严格推理"的最佳场所。建议作为代数线之后的选修。

a ≡ b (mod n) ⇔ n | (a−b)；(ℤ/nℤ)ˣ 是阶 φ(n) 的群
费马小定理：p 素数 ⇒ a^p ≡ a (mod p)
二次互反律：(p/q) 与 (q/p) 的 Legendre 符号关系

核心内容：整除、GCD 与 Euclid 算法；算术基本定理；模运算与 (ℤ/nℤ)ˣ（衔接群论）；二次剩余与互反律；连分数与丢番图逼近（行星共振、KAM 的数学入口）；素数分布初步；展望：椭圆曲线、模形式及其在物理前沿的出现。

物理学家停在哪：能把模运算当作有限群练习、理解丢番图逼近为何决定共振重叠阈值，即达到"物理够用"；继续深入属于兴趣驱动。

自测：为什么 RSA 的安全性归结为分解大整数而非"素数难找"？

素性检测（如 Miller–Rabin）多项式时间可完成；而由 N = pq 反推 p、q 没有已知多项式算法，φ(N) 与 d ≡ e⁻¹ mod φ(N) 的计算依赖分解。困难在于"分"，不在"找"。

产物：用连分数展开黄金比，说明其收敛最慢为何对应"最稳定共振"（KAM 环面），给出一段物理直觉。

C13 · 拓扑 / 先修：实变函数、群论入门

拓扑：连续形变下不变的东西。

为什么需要：拓扑绝缘体的量子化电导、Berry 相位与 Chern 数、宇宙弦与磁单极（真空流形的非平凡 π）、分数化激发——凝聚态与场论近三十年的语言是拓扑。它同时是"什么是空间"这门课的现代表述。

开集公理 ⇒ 连续：原像映开集为开集
紧致 ⇔ 序列有收敛子列（度量空间）
π₁(S¹) = ℤ：缠绕数不可连续消除

核心内容：拓扑空间、连续映射与同胚；连通性与道路连通；紧致性（Heine–Borel 推广，物理中"配分函数良定义"的靠山）；基本群与覆盖空间（S¹、平面去掉一点）；同调初步（Betti 数、Euler 示性数）；流形与向量丛的直觉（为规范场论铺路）。

物理学家停在哪：能计算并解释 π₁ 与缠绕数、知道为什么"咖啡杯≠甜甜圈"的严格版本是同胚分类、能把 TKNN 不变量读作映射 T²→S² 的次数，即可。代数拓扑的完整工具（谱序列等）留给数学物理方向。

自测：为什么有限深势阱的束缚态个数有限，而谐振子的无限？

束缚态计数与势阱"吸引强度"的拓扑/变分判据（Cwikel–Lieb–Rosenblum 型）相关：紧支撑势的负能级有限；V = x² 无界，能级趋于无穷。这展示了空间完备性与紧致性如何在物理谱上留下痕迹。

产物：证明 S¹ 与 ℝ\{0} 不同胚（提示：去掉一点后的连通分量数），再解释这一不变量如何对应"缠绕能否解开"。

阶段 D / 先修：至少三门 C 课程

回归物理：课程在真实问题中会师。

课程的终点不是"学完"，而是能同时调用多门课。四个标准会师项目：

热方程与声子谱分离变量 + Fourier + 线性代数正交基 → 固体比热。量子力学公理Hilbert 空间 + 自伴谱定理 + 群表示 → 角动量与选择定则。Maxwell 与规范场矢量分析 + 复变/张量 + 群论 U(1) → 从静电到规范不变性。拓扑物态傅里叶（布洛赫带）+ 泛函（谱投影）+ 拓扑（Chern 数）→ 量子化电导。

每个项目都应产出可检查的东西：一次完整推导、一段可复现代码、或一页能讲给同学听的报告。只"看懂"不算完成。

03 / 两年规划示例

一门分析课 + 一门代数/概率课，交替推进。

建议节奏（每周 8–12 小时数学，与物理主线并行）
学期分析线代数 / 概率线会师项目
第 1 学期微积分（含级数）线性代数双摆简正模式
第 2 学期常微分方程概率论与数理统计受迫阻尼 + 噪声拟合
第 3 学期矢量分析 → 偏微分方程复变函数带电球与留数积分

选修学期泛函分析拓扑 / 数论按研究方向选会师项目

依赖关系优先于进度表：学不动 PDE 就回补 Fourier 与 ODE；群论卡住通常是因为线性代数（基变换、张量积直觉）不牢。本页 13 门课全部自测通过前，不必追求"学完数学系"。

教材与内容边界

  • OpenStax Calculus（三卷）：微积分与多元部分的主教材。
  • OpenStax Linear Algebra：线性代数入门；进阶用 Hoffman–Kunze 级别。
  • OpenStax Statistics + Casella–Berger 级别：概率统计两段走。
  • 复变：Churchill 或 Brown–Churchill；实变：Stein–Shakarchi Real Analysis；泛函：Kreyszig 或 Lax；Fourier：Stein–Weiss 或 Bracewell；ODE：Arnold 或 Tenenbaum–Pollard；PDE：Strauss；群论：Georgi（物理学家版）；数论：Hardy–Wright 或 Burton；拓扑：Munkres 前半 + Nakahara（物理应用）。
