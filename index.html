六个数学桥梁量纲与比例导数与近似积分与累积向量与矩阵微分方程误差传播

01 / 先修：分数、幂与平方根

量纲：先检查关系，再代入数字。

速度的量纲是长度除以时间，记为 LT⁻¹。单位可以从米每秒换成千米每小时，但量纲不变。能相加的物理量必须有相同量纲；sin、exp 等函数的自变量应当无量纲。

设理想单摆周期只依赖摆长 ℓ 和重力加速度 g，尝试 T = Cℓᵃgᵇ。比较长度和时间的幂次：

[T] = Lᵃ(LT⁻²)ᵇ → a + b = 0，−2b = 1
T = C√(ℓ/g)

由此得到 a = 1/2、b = −1/2。量纲不能给出 C = 2π，也不能排除周期依赖无量纲的振幅。小角度结果还需运动方程支持。

物理判断：同样重力下，摆长变为 4 倍，周期变为 2 倍；不是 4 倍。先算比例，往往比代入全部数字更清楚。

练习：T = 2πℓ/g 能否作为周期公式？

不能。ℓ/g 的量纲为时间平方，乘无量纲的 2π 后仍是时间平方。量纲错误足以否定公式；量纲正确却不足以证明公式。

留下一个产物：任选一个熟悉公式，写出两边量纲，并说明量纲检查不能检验的部分。

02 / 先修：函数、极限的直觉、弧度

导数：描述局部变化，而不是整段平均。

在一小段时间内，Δx/Δt 是平均速度。让时间间隔趋近于零，得到瞬时速度 v = dx/dt。再对速度求导，得到加速度。若 x = At²，且 A 的单位为 m/s²，那么 v = 2At、a = 2A。

f(x + Δx) ≈ f(x) + f′(x)Δx

这是局部线性近似：函数足够平滑、增量足够小时，可以用切线代替曲线。近似精度取决于被忽略的高阶项，而不只是“数值看起来小”。

单摆中，θ 以弧度表示，sin θ = θ − θ³/6 + …。忽略三次及更高项就得到 sin θ ≈ θ。在 θ = 0.1 rad 时，三次项相对 θ 约为 0.1²/6 ≈ 0.17%。这衡量函数近似的量级，不能直接当成周期误差。

练习：为什么不能把 sin 5° 近似为数字 5？

展开式使用弧度。5° = π/36 ≈ 0.0873 rad，所以 sin 5° ≈ 0.0873。把角度制的数值直接代入会破坏近似的尺度。

留下一个产物：画一条曲线和切线，标出在哪个邻域可以近似，以及离开邻域后偏差怎样增加。

03 / 先修：函数图像、导数与面积

积分：把一段段局部贡献加起来。

若力沿一维位移方向变化，把路径分成小段，每段做功近似为 F(x)Δx；细分并求和得到定积分。它是带符号的累积，曲线在横轴下方的贡献为负。

W = ∫x₁x₂ F(x) dx

理想弹簧对物体的力为 F = −kx。从平衡位置拉到 x，弹簧力做功 −kx²/2，弹性势能增加 kx²/2。若外力缓慢拉伸且忽略耗散，其做功为正的 kx²/2。

不要把末端最大力 kx 乘整段位移作为答案：这会把变化的力当成常量。对线性弹簧，平均力的大小为 kx/2。多维路径上应使用 ∫F·dr，方向也参与计算。

练习：k = 100 N/m，缓慢拉伸 0.10 m，外力做功多少？

W = (1/2) × 100 × 0.10² = 0.50 J。若答案为 1 J，检查是否把最终力用于整个过程。

留下一个产物：画出 F–x 图，用面积解释功的数值与正负号，并标明讨论的是谁施加的力。

04 / 先修：平面坐标、三角函数

向量与矩阵：把方向写进关系。

向量同时包含大小和方向。坐标分量依赖基底，物理向量本身不因换坐标而改变。在正交单位基底中，F·Δr = FₓΔx + FᵧΔy，等于 |F||Δr| cos φ。

例如 F = (3, 4) N，Δr = (2, 0) m，恒力做功为 6 J；力的大小为 5 N，却不能不考虑夹角就得到 10 J。

R(θ) = [ cos θ　−sin θ ; sin θ　cos θ ]
r′ = R(θ)r

这里把列向量在固定坐标系中逆时针旋转 θ，称为主动旋转。如果改为坐标轴逆时针旋转 θ，而物理向量不动，分量变换应使用 R(−θ)。先说清约定，再使用矩阵。

R 的列向量互相正交且长度为一，因此旋转保持长度。更一般的线性变换未必如此。特征向量满足 Av = λv（v ≠ 0），表示方向在变换下保持共线；矩阵不一定拥有足够的实特征向量。

练习：把 (1, 0) 主动逆时针旋转 90°，得到什么？

得到 (0, 1)。如果结果是 (0, −1)，检查采用的是主动旋转还是被动坐标变换，以及角度正方向。

留下一个产物：用图和坐标分别表示同一次旋转，核对长度不变。

05 / 先修：导数、三角函数与初始条件

微分方程：从变化规律推回运动。

牛顿第二定律把力与加速度联系起来。理想弹簧满足 mx″ = −kx，即 x″ + ω²x = 0，其中 ω² = k/m。尝试余弦形式，并把它代回原方程检查。

x(t) = A cos(ωt) + B sin(ωt)
x(0) = x₀，x′(0) = v₀ → A = x₀，B = v₀/ω

方程给出一族运动，初始位置和速度选出其中一个。周期是 2π/ω。小角单摆满足同样结构的方程，但 ω² = g/ℓ；数学形式相同，参数的物理意义不同。

加入线性阻尼后，方程变为 mx″ + bx′ + kx = 0，振幅通常衰减；受驱动时还要加入外力。不能继续把无阻尼余弦解当作通用答案。

练习：初始位移为零，初始速度 v₀ > 0，应选余弦还是正弦项？

此时 A = 0，B = v₀/ω，故 x = (v₀/ω)sin(ωt)。代入 t = 0 检查位置，再求导检查初速度，比凭图形记忆更可靠。

留下一个产物：写出一个候选解，检查方程、初始条件和量纲。继续到 主站单摆学习路线，把这些检查用在真实问题结构上。

06 / 先修：偏导数与标准不确定度的概念

误差传播：输入的不确定性怎样进入结果？

测量值不是无误差的真值。若 y = f(x₁, x₂, …)，在输入波动足够小、函数可局部线性化时，用各偏导数描述结果对输入的敏感程度。对不相关输入：

u²(y) ≈ Σ (∂f/∂xᵢ)²u²(xᵢ)

有相关性时，需要加入协方差交叉项，不能直接平方相加。标准不确定度也不等于最大误差；系统偏差需要识别、校正并评估，重复测量不一定能消除它。

由单摆测 g = 4π²ℓ/T²，在长度和周期不相关、相对不确定度小的条件下：

u(g)/g ≈ √[ (u(ℓ)/ℓ)² + (2u(T)/T)² ]

若长度相对标准不确定度为 1%，周期为 0.5%，合成结果约为 √(1² + 1²)% ≈ 1.41%。这还没有自动包含有限振幅、装置模型偏差等影响。

练习：只增加计时重复次数，能保证 g 越来越准确吗？

不能。若长度零点偏差或小角模型误差占主导，重复计时只改善部分随机分量。应先建立不确定度预算，识别最主要来源，再选择改进方向。

留下一个产物：列一张“输入量—来源—标准不确定度—相关性”的表，说明哪些来源尚未纳入。可继续阅读 Ultra 的不确定性与结果报告。
