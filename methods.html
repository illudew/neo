07 / 先修：积分、正交、复数指数

Fourier：用简单模式组织复杂变化。

周期函数可以在适当条件下用正弦、余弦模式展开。复数指数 eiθ = cos θ + i sin θ 将它们写成一种形式；i² = −1，最后的物理信号仍可为实数。设周期为 P，在平方可积意义下：

f(t) = Σ cₙ einω₀t，ω₀ = 2π/P
cₙ = (1/P)∫₀ᴾ f(t)e−inω₀t dt，n ∈ ℤ

系数来自模式之间的正交性。若 f(t) = 3 cos(ω₀t) + 2 sin(2ω₀t)，实数展开的第一余弦系数是 3，第二正弦系数是 2。复数展开中 c₁ = c₋₁ = 3/2，c₂ = −i，c₋₂ = i。归一化不同，系数数值可能不同，比较前先写清定义。

对分段光滑的周期函数，在跳跃处级数收敛到左右极限的平均；附近会有 Gibbs 现象。有限项不会神奇地保留任意尖锐结构。

连续函数进入计算机以后

采样间隔 Δt 对应采样率 fₛ = 1/Δt，N 点离散 Fourier 变换的频率栅格间隔为 Δf = fₛ/N。它是栅格间隔，不是任意情况下都能分开两条谱线的保证；窗函数、噪声和观测时长都会影响判断。零填充能加密栅格，不能增加已经采集的信息。

理想带限信号若要避免混叠，最高频率须低于 fₛ/2，并需考虑采样前的抗混叠滤波。以 10 Hz 采样 cos(2π·8t)，得到的样本与 2 Hz 余弦相同，因此仅凭这些样本无法分辨二者。

练习：以 100 Hz 采集 200 点，频率栅格间隔是多少？能唯一识别 70 Hz 分量吗？

Δf = 0.5 Hz，Nyquist 频率为 50 Hz。70 Hz 超出这个范围，在该采样下会折叠到 30 Hz；没有额外先验或重新采样，不能唯一识别。

产物：写清采样率、点数、观测条件和窗函数，再解释一条谱峰能支持什么结论。继续阅读 Pro Max 光谱专题。

08 / 先修：平均数、平方与随机变量

统计：从有限观测判断不确定性。

随机变量描述可能结果；期望是概率分布下的平均，并不要求等于某一次观测。对 n 个独立、同分布、方差有限的观测 xᵢ，常用样本平均与样本标准差为：

x̄ = (Σxᵢ)/n
s² = Σ(xᵢ − x̄)²/(n − 1)，n ≥ 2
估计的均值标准误：s/√n

s 描述单次观测的离散程度，s/√n 描述平均值的随机不确定性估计。若观测相关、仪器漂移或方差不稳定，就不能机械使用独立样本公式。标准误也不自动包含校准偏差。

例如测得周期 1.98、2.00、2.02 s，平均是 2.00 s，样本标准差是 0.02 s，均值标准误约 0.01155 s。三者回答不同问题；报告时应注明样本数和误差条定义。

在独立正态样本、总体方差未知等条件下，均值的置信区间可用 Student t 分布构造。不要把“均值 ± 一个标准误”称为 95% 置信区间，尤其不能忽略小样本系数。

练习：同一次仪器读数复制十遍，标准误能因此可靠缩小吗？

不能。复制不是新增独立信息。反复测量也可能受共同偏差影响，必须说明独立重复的定义与误差来源。

产物：为一组重复测量分别报告 x̄、s、n 和随机性假设，再列出未包含的系统项。可与 误差传播连接。

09 / 先修：偏导数、常微分方程、Fourier

偏微分方程：空间与时间一起变化。

温度 u(x,t) 同时依赖位置和时间。∂u/∂t 是固定 x 时的变化率，∂²u/∂x² 描述空间曲率。方程之外，定义域、材料参数、边界条件和初始条件同样属于问题本身。

热方程：∂u/∂t = α ∂²u/∂x²，α > 0
波动方程：∂²u/∂t² = c² ∂²u/∂x²
Laplace 方程：∇²u = 0

第一式描述恒定扩散率、无源项的一维扩散模型；第二式可描述均匀弦的小横向振动；第三式出现在无源稳态问题。不同模型的初始条件数量和边界要求不同，不能互相套用。经典分类也不能直接覆盖一切非线性方程。

从分离变量到边界选择的模式

考虑 0 < x < L 上的热方程，固定端温度相对参考值为零：u(0,t) = u(L,t) = 0。设 u = X(x)G(t)，代入后有 G′/(αG) = X″/X = −λ。边界条件选出 λₙ = (nπ/L)² 与 Xₙ = sin(nπx/L)。

u(x,t) = Σ bₙ sin(nπx/L) exp[−α(nπ/L)²t]
bₙ = (2/L)∫₀ᴸ u(x,0)sin(nπx/L) dx，n = 1,2,…

初始温度分布决定各模式的系数；高空间频率衰减更快。这里的 α 单位为长度平方/时间，使指数无量纲。若初始分布与边界在角点不相容，不能直接假设解处处光滑。

固定端弦也出现同样的空间正弦模式，但时间因子为振荡形式，其频率 ωₙ = cnπ/L；还需初始位移与初始速度两项信息。热方程只需初始温度。

练习：若初始温度是 sin(2πx/L)，它会演化成什么？

u = sin(2πx/L)exp[−4απ²t/L²]。检查：t = 0 恢复初值，两端为零，代入方程两边相等。若指数是正号，扩散反而放大起伏，应重新检查符号。

产物：选热方程或波动方程，完整写出定义域、参数、初始/边界条件，再代入检验一个解。

10 / 先修：导数、方程与误差

数值计算：把近似误差也纳入答案。

数值方法在有限网格和有限精度下近似连续问题。程序能运行，仅说明完成了一次计算；还需验证实现、离散化误差与模型是否适合物理问题。

以无量纲方程 y′ = −y，y(0) = 1 为基准，精确解为 e⁻ᵗ。前向 Euler 法取 yₖ₊₁ = yₖ − hyₖ；在固定终点 t = 1、h = 1/N 时，有 yᴱ(1) = (1 − 1/N)ᴺ。

误差 E(N) = |(1 − 1/N)ᴺ − e⁻¹|
观测阶数 p ≈ log₂[E(N)/E(2N)]

对足够小的步长，Euler 的全局误差通常为一阶，误差比接近 2。本例的显式迭代稳定范围是 0 < h < 2，但“稳定”不代表“精确”；h > 1 时还会产生交替符号，与正值精确解不同。

热方程的显式差分

uⱼⁿ⁺¹ = uⱼⁿ + r(uⱼ₊₁ⁿ − 2uⱼⁿ + uⱼ₋₁ⁿ)
r = αΔt/Δx² ≤ 1/2

此条件针对一维、常 α、均匀网格的前向时间/中心空间离散，在常见齐次边界处理下的标准稳定性分析。不能推广为所有 PDE 或所有算法的条件。网格间距减半时，显式时间步上限缩小到四分之一；仍需检验边界处理与收敛。

  1. 先用有解析解的简单问题检查代码。
  2. 固定物理终点和边界，逐步细化网格/步长，比较目标量。
  3. 分别检查离散误差、舍入误差和模型误差，记录实际采用的分辨率。
  4. 保存输入、版本、单位与执行方式；出现异常时检查稳定性，不能只换一个看起来正常的参数。
练习：Δx 减半而 Δt 不变，r 如何变化？

r 增大到 4 倍。原先稳定的计算可能失稳；若同时把 Δt 缩小到四分之一，r 才保持不变。

产物：一张网格/步长、结果与误差表，并解释为什么信任当前精度。下方工作台可先练习 Euler 收敛和热方程稳定性判断。

11 / 先修：向量、矩阵、偏导数与坐标变换

张量：对象不变，分量按规则改变。

矩阵是一种排列数值的形式；判断某个量是不是张量，需要知道它在坐标改变时如何变换。以求和约定书写，重复的一个上标和一个下标表示求和，而不是幂。

v′ⁱ = (∂x′ⁱ/∂xʲ)vʲ
ω′ᵢ = (∂xʲ/∂x′ⁱ)ωⱼ
ω′ᵢv′ⁱ = ωᵢvⁱ

向量分量与协向量分量使用互逆的变换，收缩得到的标量不随坐标改变。标量场 f 的微分 df = (∂ᵢf)dxⁱ 是协向量；梯度向量需要度量将指标升起。在笛卡尔正交单位基底中，上下标数值可能相同，但概念不能混淆。

平面中的极坐标例子

ds² = dr² + r²dθ²
gᵢⱼ = diag(1, r²)，v² = (vʳ)² + r²(vᶿ)²

这里 vʳ = dr/dt，vᶿ = dθ/dt，是坐标基底下的分量。沿圆周运动时 dr/dt = 0，速率是 r|dθ/dt|，不是单独的角速度。坐标基底与局部正交单位基底不同；r = 0 处极坐标存在坐标奇点。

二阶协变张量按两个逆 Jacobian 变换。更高阶张量每个指标各有相应变换因子。曲线坐标中的基底会随位置改变，因此向量场分量的普通偏导一般不能单独组成张量；需要加入连接项构成协变导数。

练习：半径 2 m，角速度 3 rad/s 的匀速圆周运动，速率是多少？

速率为 6 m/s；其平方由度量给出 4 × 9 = 36 m²/s²。这也说明把角分量直接当成线速度会导致单位错误。

产物：分别用笛卡尔坐标和极坐标描述同一小位移，核对 ds² 相等。深入学习时再连接应力张量、电磁场张量和相对论，不把所有下标数组直接当作张量。

12 / 先修：集合、矩阵乘法与旋转

群论：研究变换如何组合。

一组变换与一种组合运算构成群，需要满足封闭、结合律、有单位元、每个元素有逆元。交换律不是必需条件。群论帮助描述物理规律或系统在什么变换下保持不变。

SO(2)：R(θ) = [ cos θ　−sin θ ; sin θ　cos θ ]
R(θ)R(φ) = R(θ + φ)，R⁻¹(θ) = R(−θ)

SO(2) 表示二维保长度、保定向的线性旋转，角度以 2π 为周期，彼此交换。三维绕不同轴旋转一般不交换。例如先绕 x 轴再绕 z 轴，与相反次序可能得到不同结果，必须标明矩阵乘法作用的顺序。

表示：让抽象组合作用到向量空间

群表示 D 将群元素映成可逆线性变换，并满足 D(g₁g₂) = D(g₁)D(g₂)。物理中可以用表示分析状态、模式与算符如何变换；表示的维数不一定等于物理空间维数。

以二元群 C₂ = {e, s}，s² = e 为例。函数上的反演算符 P 满足 Pf(x) = f(−x)，P² = I；偶函数满足 Pf = +f，奇函数满足 Pf = −f。若算符 H 与 P 对易，H 会保持偶、奇子空间；在适当条件下可据此分类本征态。

对称性可约束允许的耦合、简并与选择定则，但“有对称性就一定简并”不成立。Noether 定理把满足相应条件的连续作用量对称性与守恒量联系起来，不能把任意离散对称直接套成一个 Noether 守恒量。

练习：f(x) = x² + x 不是纯奇函数或偶函数，如何分解？

f₊ = [f(x)+f(−x)]/2 = x²，f₋ = [f(x)−f(−x)]/2 = x。两者之和恢复原函数，反演下分别乘 +1 和 −1。

产物：写出一个变换集合的单位元和逆元，检验组合关系，再说明它对哪一个物理对象构成对称。继续阅读 群论知识页面。
